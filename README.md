This mod adds visual "physics" to dropped items on Ornithe 1.8.9.
![Example image](https://cdn.modrinth.com/data/cached_images/68c9a6eb04e1df859438be64a69cb67e3072790a.png)

No dependencies are required for this mod.

While this mod contains no code from the original [ItemPhysic-Lite](https://modrinth.com/mod/itemphysic-lite) mod, I recommend that you use it for its supported versions.

Modrinth: https://modrinth.com/mod/ornitheitemphysiclite
